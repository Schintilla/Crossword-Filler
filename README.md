# Crossword-Filler
Crossword Manager
Electronically fill Crosswords only available as hardcopies or not readily available for completion on-line. 

Only need a Crossword image plus its clues. Clues are saved as png unless OCR'd

Use OCR directly from the screen or paste from cliboard or from the loaded image file

Image scan will depend on quality. Pre-processing may help 

Use on-the-fly pre-processing to scale, sharpen, threshold, denoise etc

A place to also store all your Crosswords still to be completed. You can browse and revisit for completion at any time.

Also has import and export options to share Crosswords. Can read and write puz and ipuz which is better than scanning and OCR, and may also include the solution and hints

Finally, various other features to assist the stubborn and obscure clues, particularly useful for Cryptic Crosswords. 
A Clues Explorer to aid anagram, clue disecting, matching letters, process of elimination etc. 
A scratchpad for your ruminations and thinking out aloud. 
An ability to compile a database of hints and common clue techniques for future reminder.
Online dictionaries for word and phrase searches 
Last but not least an AI lookup!
